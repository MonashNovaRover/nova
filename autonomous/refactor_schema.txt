HOW TO DO REFACTOR TO THIS SCHEMA:
all directories inside autonomous/autonomous (including the directory itself) need an __init__.py

in each file, write 
__package__="autonomous"

When you import, you don't need to write:
"from autonomous.package import thinkgo"
instead: 
from package import thingo
