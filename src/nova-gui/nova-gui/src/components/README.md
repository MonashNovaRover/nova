# Components

If you are creating a new component please look in the shared folder first to see if there's anything you can reuse!
When you are making something new if it can be made generic add it to the sharded folder!

## Folder structure

- **arm** - Arm related components. Can be specific to the arm or arm-related competition tasks.
- **auto** - Auto related components.
- **cameras** - Camera related components.
- **drive** - Drive related components.
- **maps** - For map related components including things like gps if applicable.
- **navbar** - Any components located in either the side or top navbar that are on all pages.
- **science** - Science related components.
- **shared** - Any reusable components.
  - **components** - Any reusable components.
  - **widgets** - Any reusable widgets.
