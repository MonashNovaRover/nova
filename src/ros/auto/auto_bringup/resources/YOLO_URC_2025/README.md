This folder contains the YOLOv11 model we used at URC 2025.
This YOLO model detects an Orange mallet and a 1L water bottle with a wide mouth.


### TEMPLATE
This model was only used in RGB mode and with object_localiser.py (in `rover/nova_utils`)

Trained using roboflow dataset and ultralytics by Chetan Edupalli
Converted for use on OAK-D LR using https://tools.luxonis.com/
Ran using ../../launch/yolo.launch.py

Details here: https://www.notion.so/Cube-Detection-19db713961718033b820fc406df6697f
