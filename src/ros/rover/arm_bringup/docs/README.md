# New Armware Documentation

Written by Bailey Chessum, May 2025

---

This documentation is intended to:
1. Teach the concepts underlying the design of the new arm software.
2. Outline the current structure of new arm software.
3. Enable others to continue to experiment, build upon, and change the arm software.

I believe the first point is more important to address, as I anticipate the exact structure of armware to change in the 
future.
