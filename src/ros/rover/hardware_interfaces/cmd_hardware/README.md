# blcmd_hardware

This is a custom `ros2_control` hardware interface used to control the CMDs for the old arm. It communicates directly with any active `ros2_control` controllers via the Controller Manager.

Consult `ros2_control` [documentation](https://control.ros.org/rolling/doc/ros2_control/hardware_interface/doc/writing_new_hardware_component.html) on how to write a hardware interface.
