# diff_drive_controller

This drive controller implements a differential drive model. Differential drive is where the pivots stay parallel and turning is done by varying the speeds of the wheels on each side. For example, a higher speed on the left wheels will cause the rover to turn right. Opposite speeds on each side (e.g. -1, 1) will cause the rover to spin on the spot.

## Notes:
- Also known as Tank Mode or Tank Drive.
