# 900MHz radios related code 
copied from [Antenna Tracking FYP](https://github.com/MonashNovaRover/antenna-tracking)

## Usage
Terminal:
```./run_terminal.sh```
This script builds and runs the control terminal for the 900MHz radios.
You can type in `AT+` and press `Enter` to show a list of available commands.
Refer to the [Datasheet](https://github.com/MonashNovaRover/antenna-tracking/blob/master/firmware/docs/AH.module.AT.command.development.guide_.ENGLISH.pdf) for the full list of commands and
